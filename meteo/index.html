Accéder à ICON-CH1 et ICON-CH2

MeteoSuisse publie ses deux modèles en Open Government Data depuis mai 2025. Deux voies existent : les fichiers bruts GRIB2 de MeteoSuisse (voie officielle, complète, lourde) ou Open-Meteo (même modèle, déjà décodé et servi en JSON). Le prototype utilise la seconde ; la première sert pour aller plus loin (ensembles, niveaux d'altitude).

Les fichiers ne restent en ligne que 24 h. Les échéances d'un run n'arrivent pas toujours dans l'ordre : une requête faite pendant la publication peut mélanger deux runs.

Voie 1 · STAC API MeteoSuisse (GRIB2)

Un fichier GRIB2 = un modèle, un run, une échéance, une variable (contrôle ou ensemble complet). Recherche par POST sur https://data.geo.admin.ch/api/stac/v1/search :

{
  "collections": ["ch.meteoschweiz.ogd-forecasting-icon-ch1"],
  "forecast:reference_datetime": "2026-11-01T06:00:00Z",
  "forecast:variable": "U_10M",
  "forecast:perturbed": false,
  "forecast:horizon": "P0DT04H00M00S"
}

La réponse contient sous assets un lien pré-signé à télécharger. Variables vent utiles : U_10M, V_10M (composantes, m/s) et VMAX_10M (rafales). Vitesse = √(U²+V²) ; direction d'où vient le vent = atan2(−U, −V).

Point délicat : la grille est icosaédrique (triangles), sans coordonnées dans les fichiers. Il faut le fichier horizontal_constants_icon-ch1-eps.grib2 (CLON/CLAT, et FR_LAKE pour repérer le lac), vérifier uuidOfHGrid, puis interpoler vers les points voulus. Décodage avec ecCodes et les définitions COSMO (GRIB_DEFINITION_PATH).

En Python, la bibliothèque meteodata-lab de MeteoSuisse fait tout cela et accepte ref_time="latest" :

from meteodatalab import ogd_api
req = ogd_api.Request(collection="ogd-forecasting-icon-ch1",
      variable="U_10M", ref_time="latest",
      perturbed=False, lead_time="P0DT4H")
u = ogd_api.get_from_ogd(req)   # xarray avec lon/lat

Pour savoir si un fichier a changé sans le retélécharger, utiliser l'en-tête If-None-Match ; l'intégrité se vérifie avec x-amz-meta-sha256.

Voie 2 · Open-Meteo (JSON, utilisée ici)

Point d'entrée https://api.open-meteo.com/v1/forecast avec models=meteoswiss_icon_ch1, meteoswiss_icon_ch2 ou meteoswiss_icon_seamless (CH1 puis CH2). L'ancien chemin /v1/meteoswiss n'existe plus. Variables : wind_speed_10m, wind_direction_10m, wind_gusts_10m ; wind_speed_unit=kn ; plusieurs points en séparant latitudes et longitudes par des virgules ; cell_selection=nearest prend la maille du modèle la plus proche ; sea privilégie les mailles d'eau, mais près de Dorigny elles sont repoussées au large (4 mailles distinctes au lieu de 7 pour nos sondes).

Open-Meteo reprojette la grille icosaédrique sur une grille régulière de résolution voisine et calcule vitesse et direction depuis U et V. Gratuit sans clé pour un usage non commercial ; appels CORS autorisés, donc utilisable directement depuis une page GitHub Pages. Pour savoir quand un run est arrivé : https://api.open-meteo.com/data/meteoswiss_icon_ch1/static/meta.json (champ last_run_availability_time ; attendre ~10 min de plus).

Logique « toujours le dernier run »
  • Le dernier run disponible se calcule : heure actuelle moins le délai de publication, arrondie au multiple de 3 h (CH1) ou 6 h (CH2) en UTC. Le bandeau en haut applique cette règle.
  • La page programme le prochain rechargement à l'heure de disponibilité suivante + 10 min, puis contrôle meta.json pour confirmer.
  • Pour une date donnée, CH1 ne la couvre que si elle est à moins de 33 h du run : pour la course du dimanche, CH1 apporte la maille fine à partir du run de samedi matin ; avant, seul CH2 est disponible.
Pistes pour la version finale
  • Page web statique (GitHub Pages) : ce prototype + appel direct Open-Meteo. Le plus simple, et cohérent avec le site du Grand Prix.
  • Petit serveur Python planifié (GitHub Actions toutes les 3 h) : télécharge les GRIB2 MeteoSuisse via meteodata-lab, extrait les points du plan d'eau, publie un JSON. Donne accès aux 11/21 membres d'ensemble (probabilité de rafales > 20 nœuds) sans dépendre d'Open-Meteo.
  • App mobile : à envisager seulement si l'usage sur l'eau le demande ; une page web installable (PWA) couvre déjà le téléphone.
